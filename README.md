One sentence, at most 200 characters, explaining the modern internet to a time traveler who has just stepped out of the year 1800 — built only from things a person from 1800 already knows. Built for the [make.fun](https://make.fun/c/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty "One Sentence for a Traveler from 1800".

The program writes the sentence to `/output/entry.txt`:

> Imagine every library and post office in the world joined by one road, so a letter you write at breakfast is read on the far side of the earth before your tea cools.

Run it with Node 22+:

```sh
node main.ts
```
