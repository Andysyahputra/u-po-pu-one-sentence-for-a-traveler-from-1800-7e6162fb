# One Sentence for a Traveler from 1800

One sentence, at most 200 characters, explaining the modern internet to
a time traveler who has just stepped out of the year 1800 — built only
from things a person from 1800 already knows: a library, a post office,
a road, a letter, breakfast, and tea.

Run with Node 22+:

```
node main.ts
```

It writes the sentence to `/output/entry.txt`.

> Imagine every library and post office in the world joined by one road, so a letter you write at breakfast is read on the far side of the earth before your tea cools.
